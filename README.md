# Telegram-бот-визитка для бизнеса

Простой бот для небольшого бизнеса: показывает услуги и цены, отвечает на
частые вопросы, принимает заявки и пересылает их владельцу.

> Демо для вымышленной «Студии красоты „Лаванда“». Под любого клиента бот
> переделывается заменой текстов в одном файле — `src/content.ts`.

**Демо:** https://t.me/lavanda_demo_dsgn_bot (@lavanda_demo_dsgn_bot)

## Возможности

| Раздел | Что происходит |
| --- | --- |
| `/start` | Приветствие с названием бизнеса и меню: «Услуги и цены», «Частые вопросы», «Оставить заявку», «Контакты» |
| Услуги и цены | 5 услуг: название, описание, цена «от». Кнопки «Оставить заявку» и «Назад» |
| Частые вопросы | 5 вопросов кнопками, по нажатию — ответ. Кнопка «Назад» |
| Оставить заявку | Диалог: услуга → имя → контакт → комментарий (можно пропустить) → сводка с кнопками «Отправить» / «Отменить» |
| Контакты | Адрес, телефон, часы работы, кнопка сайта |
| `/help` | Список возможностей |
| `/cancel` | Прервать заявку на любом шаге |
| `/stats` | Только для администратора: пользователи и заявки за сегодня и всего |

Владельцу в `ADMIN_CHAT_ID` приходит сообщение: номер заявки, услуга, имя,
контакт, комментарий, ссылка на профиль и время.

**Надёжность и защита**

- не больше 3 заявок в час от одного пользователя;
- ввод очищается от невидимых и управляющих символов, длина полей ограничена
  (имя — 64, контакт — 100, комментарий — 500 символов);
- фото, стикер или голосовое вместо текста → «Пожалуйста, пришлите текст»;
- заявка сначала сохраняется в базу, потом отправляется владельцу: если
  отправка не удалась, заявка не теряется, ошибка пишется в лог;
- повторное нажатие «Отправить» не создаёт дубль;
- токен и ID администратора — только в `.env`, файл в `.gitignore`;
- логи в консоль: запуск, новые заявки, ошибки.

## Стек

Node.js 20, TypeScript, [grammY](https://grammy.dev), SQLite
(better-sqlite3), Vitest. Диалог заявки — собственная простая машина
состояний без дополнительных плагинов. Docker и docker-compose для продакшена.

## 3. Запуск локально

Нужен Node.js 20+.

```bash
npm install
cp .env.example .env     # и впишите BOT_TOKEN и ADMIN_CHAT_ID
npm run dev              # запуск с автоперезагрузкой (polling)
```

Откройте бота в Telegram и отправьте `/start`.

Другие команды:

```bash
npm test                 # тесты (сценарии бота, база, валидация)
npm run build            # сборка в dist/
npm start                # запуск собранной версии
```

База создаётся автоматически в `./data/bot.db` и переживает перезапуск.

## 4. Запуск через Docker

```bash
cp .env.example .env     # впишите BOT_TOKEN и ADMIN_CHAT_ID
docker compose up -d --build
docker compose logs -f   # логи бота
```

- База хранится в томе `bot-data` и не теряется при перезапуске и пересборке.
- `restart: unless-stopped` — бот поднимется сам после перезагрузки сервера.
- Обновление: `git pull && docker compose up -d --build`.
- Остановка: `docker compose down` (база останется в томе).

## Как переделать под клиента

Всё, что видит пользователь, находится в `src/content.ts`:

- `business` — название и короткое описание;
- `services` — услуги (название, описание, цена «от»);
- `faq` — вопросы и ответы;
- `contacts` — адрес, телефон, часы работы, сайт;
- `buttons`, `texts`, `leadLabels` — подписи кнопок и сообщения;
- `timeZone` — часовой пояс для времени заявок и статистики «за сегодня».

Логику (`bot.ts`, `leadFlow.ts`) при этом трогать не нужно.

## Данные (SQLite)

| Таблица | Поля |
| --- | --- |
| `users` | id, telegram_id, username, first_name, created_at |
| `leads` | id, user_id, service, name, contact, comment, status (по умолчанию `new`), created_at |

Посмотреть заявки можно любым SQLite-клиентом (например, DB Browser for
SQLite) или из консоли:

```bash
sqlite3 data/bot.db "SELECT id, service, name, contact, created_at FROM leads ORDER BY id DESC LIMIT 20;"
```

```
  utils.ts        очистка текста, экранирование HTML, время
  *.test.ts       тесты
.env.example
Dockerfile
docker-compose.yml
```
